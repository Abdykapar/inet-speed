# inet-speed

Консольный скрипт для замера скорости скачивания. Он делает N запросов подряд (по умолчанию 10) к указанному адресу и на каждом дожидается полного ответа. Потом считает среднее время запроса, общий объём скачанных данных и скорость.

## Требования

- Python 3.8+
- Сторонних зависимостей нет, нужна только стандартная библиотека.

## Запуск

```bash
git clone <url-этого-репозитория>
cd inet-speed
python3 speedtest.py <URL>
```

Пример:

```bash
python3 speedtest.py https://proof.ovh.net/files/10Mb.dat
```

Параметры:

| Параметр | По умолчанию | Описание |
|---|---|---|
| `url` | — | Адрес для скачивания (http/https), например тяжёлая картинка |
| `-n`, `--requests` | `10` | Сколько запросов сделать подряд |
| `-t`, `--timeout` | `30` | Таймаут одного запроса в секундах |

## Пример вывода

```
URL: http://example.com/big.jpg
  # 1:     5.00 MB in  0.412 s
  ...
  #10:     5.00 MB in  0.398 s

Requests:             10
Average request time: 0.405 s
Total downloaded:     50.00 MB (50000000 bytes)
Download speed:       98.77 Mbit/s (12.35 MB/s)
```

## Единицы измерения

- **Скорость** выводится в **Мбит/с** (мегабиты в секунду, 1 Мбит = 1 000 000 бит), как её обычно указывают провайдеры. В скобках та же скорость в **МБ/с** (1 МБ = 1 000 000 байт).
- **Объём** указан в **МБ** (десятичные мегабайты) и в байтах.
- **Время** указано в **секундах**.

## Как считается

- Время запроса берётся от отправки запроса до получения последнего байта тела ответа (`time.perf_counter`).
- Среднее время запроса = сумма времён / число запросов.
- Скорость = общий объём / суммарное время всех запросов.
- Чтобы цифры не искажались, отправляются заголовки `Cache-Control: no-cache` и `Accept-Encoding: identity`, то есть сервер не должен отдавать ответ из кеша или сжимать его.
- Если хотя бы один запрос завершается ошибкой (сеть, HTTP 4xx/5xx, таймаут), скрипт печатает причину и выходит с кодом `1`.
